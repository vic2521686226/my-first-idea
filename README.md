# Do It or Not

A tiny, self-contained decision tool. Click the button in the center of the page to receive a random answer: **“Just do it.”** or **“Don't do it.”**

## Open it

No installation or build step is needed. Open [index.html](index.html) in any modern web browser. On macOS, you can also double-click the file in Finder.
